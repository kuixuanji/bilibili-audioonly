**哔哩哔哩 PC 播单听视频**

适用于哔哩哔哩 Windows 客户端 1.20.0，可在普通视频和“稍后再看/收藏夹”等播单中使用听视频。

使用方法

1. 打开普通在线视频，或从播单打开视频，等视频开始播放。
2. 将 src/playlist-listen-console.js 全文粘贴到播放窗口的 DevTools Console 并执行。
3. 点击播放器的听视频按钮进入听视频，再点“切回视频”恢复画面。

播单的顺序播放会在加载完整后首尾衔接，随机播放也留在当前播单。播单内切回视频时，脚本会尝试恢复进入听视频前的清晰度。当前视频缺少同等清晰度时，选择可用的最高分辨率。普通播放页会在内存中开启 `pc_listen`，通过播放器原有的条件显示听视频按钮。

脚本只在当前播放窗口生效。播单内可运行 `window.stopPlaylistListen()` 停止脚本并切回视频。刷新窗口会清除临时改动。

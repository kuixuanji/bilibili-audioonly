**哔哩哔哩 PC 播单听视频**

适用于哔哩哔哩 Windows 客户端 1.20.0，可在普通视频和“稍后再看/收藏夹”等播单中使用听视频。

使用方法

1. 通过命令行"哔哩哔哩.exe" --remote-debugging-port=9222进入开发者模式
2. 打开在线视频，或从播单打开视频，等视频开始播放。
3. 打开127.0.0.1:9222，进入播放窗口打开 DevTools。
4. 将 src/playlist-listen-console.js 全文粘贴到播放窗口的 DevTools Console 并执行。
5. 即可点击播放器的听视频按钮进入听视频。
6. 命令行和浏览器窗口都可以直接关闭不影响使用。

播单的顺序播放会在加载完整后首尾衔接，随机播放也留在当前播单。播单内切回视频时，脚本会尝试恢复进入听视频前的清晰度。当前视频缺少同等清晰度时，临时选择可用的最高分辨率。普通播放页会在内存中开启 `pc_listen`，通过播放器原有的条件显示听视频按钮。
